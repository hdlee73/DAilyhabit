# 데일리해빗 (DailyHabit)

매일의 신앙생활과 하루 일정을 한 화면에서 챙기는 안드로이드 앱입니다.

## 기능
- **오늘의 말씀**: 한국천주교주교회의 [매일미사](https://maria.catholic.or.kr/mi_pr/missa/missa.asp)에서 오늘의 복음을 가져와 보여주고, 요일마다 바뀌는 **가정을 위한 기도**와 성가정께 드리는 기도를 함께 보여줍니다. 한 번 불러온 복음은 저장되어 오프라인에서도 볼 수 있습니다.
- **일정**: 휴대폰에 동기화된 구글 캘린더의 앞으로 7일 일정을 날짜별로 보여줍니다. (별도 로그인 없이 기기 캘린더를 읽습니다.)
- **할 일**: 중요도 · 분류 · 메모 · 마감 날짜/시각 · 마감 알림. 오늘/예정/지난 일/완료 필터와 날짜별 묶음 보기, 삭제 되돌리기.
- **루틴**: 매일 반복할 습관을 요일·알림 시각과 함께 등록하고 체크합니다. 알림에서 바로 '완료'를 누를 수 있고, 연속 기록 · 7일/30일 달성률 · 12주 기록 · 월별 달력으로 통계를 봅니다.
- 데이터는 모두 휴대폰에만 저장됩니다.
- **아침 9시 알림**: 매일 오전 9시에 오늘의 복음, 가정을 위한 기도, 오늘 일정, 남은 할 일을 알려줍니다. 말씀 탭의 🔔 버튼으로 알림을 미리 받아볼 수 있습니다.

## 설치
[Releases](https://github.com/hdlee73/DAilyhabit/releases/latest)에서 `DailyHabit-*.apk`를 내려받아 설치하세요.
처음 실행할 때 **캘린더**와 **알림** 권한을 허용해야 일정과 9시 알림이 동작합니다.

구글 캘린더 일정이 보이지 않으면 휴대폰 설정 > 계정 > Google에서 캘린더 동기화가 켜져 있는지 확인하세요.

## 빌드
```bash
./gradlew assembleDebug
```
`VERSION` 파일의 버전을 올려 main에 푸시하면 GitHub Actions가 APK를 빌드해 `v<버전>` Release로 올립니다.

> 저장소에 포함된 `app/debug.keystore`는 공개 디버그 키입니다. 업데이트 설치가 끊기지 않도록 고정해 둔 것이며, 스토어 배포용이 아닙니다.
