# DailyHabit

매일의 신앙생활과 하루 일정을 한 화면에서 챙기는 안드로이드 앱입니다.

## 두 가지 버전
- **DailyHabit 천주교인용**: 오늘의 복음, 주요 기도문(가톨릭 기도서), 묵주기도 신비가 들어 있습니다. (`DailyHabit-Catholic-*.apk`, 태그 `v*-catholic`)
- **DailyHabit**: 복음·기도 대신 오늘의 명언(한국어·영어)이 들어 있습니다. (`DailyHabit-*.apk`)

## 기능
- **오늘의 말씀**: 한국천주교주교회의 [매일미사](https://maria.catholic.or.kr/mi_pr/missa/missa.asp)에서 오늘의 복음을 가져와 보여줍니다. 한 번 불러온 복음은 저장되어 오프라인에서도 볼 수 있습니다.
- **기도** (천주교인용): 「가톨릭 기도서」의 주요 기도문, 가정 기도, 평화를 구하는 기도, 2027 서울 세계청년대회 공식 기도문, 오늘의 묵주기도 신비.
- **일정**: 휴대폰에 동기화된 구글 캘린더의 앞으로 7일 일정을 날짜별로 보여줍니다. (별도 로그인 없이 기기 캘린더를 읽습니다.)
- **할 일**: 중요도 · 분류 · 메모 · 마감 날짜/시각 · 마감 알림. 오늘/예정/지난 일/완료 필터와 날짜별 묶음 보기, 삭제 되돌리기.
- **루틴**: 매일 반복할 습관을 요일·알림 시각과 함께 등록하고 체크합니다. 알림에서 바로 '완료'를 누를 수 있고, 연속 기록 · 7일/30일 달성률 · 12주 기록 · 월별 달력으로 통계를 봅니다.
- 데이터는 모두 휴대폰에만 저장됩니다.
- **아침 알림**: 설정한 시각(기본 오전 9시)에 오늘의 복음, 가정을 위한 기도, 오늘 일정, 루틴, 남은 할 일을 알려줍니다. 알림을 누르면 오늘의 복음 화면이 열립니다. 설정에서 시간 변경과 미리 받기를 할 수 있습니다.
- **맛집**: 식당 이름, 종류, 주요 메뉴, 위치, 링크, 별점, 한 줄 평, 메모, 태그, 가격대를 저장하고 지도로 열거나 공유합니다.
- **맛집 방문 기록**: 다녀온 날짜를 여러 번 기록·수정·삭제하고 '방문 달력'에서 날짜별로 봅니다.
- **월간 돌아보기**: 한 달의 기분, 루틴 달성률, 읽은 책, 다녀온 맛집, 감사한 순간을 한 장으로 정리합니다.
- **엑셀 저장**: 한 줄 일기와 맛집(방문 기록 포함)을 .xlsx로 내보냅니다.
- **한 줄 일기**: 하루 한 줄과 기분을 남기고, 연속 기록과 '1년 전 오늘'을 봅니다.
- **장보기**: (메뉴에서는 숨김, 저장된 기록은 백업에 그대로 포함)
- **독서**: 읽는 중 / 읽고 싶은 / 다 읽은 책, 읽은 쪽수 진행률, 별점과 한 줄 소감, 밑줄·메모.
- **백업·복원**: 설정에서 모든 기록을 JSON 파일 하나로 저장하고 되돌립니다 (두 판본 사이 호환).
- **앱 정보·업데이트**: GitHub 릴리스에서 내 판본의 새 버전을 확인하고 앱 안에서 내려받아 설치합니다.
- 앱을 열면 왼쪽 메뉴가 먼저 펼쳐지고, 왼쪽 위 ☰ 버튼으로 다시 열 수 있습니다.

## 설치
[Releases](https://github.com/hdlee73/DAilyhabit/releases/latest)에서 `DailyHabit-*.apk`를 내려받아 설치하세요.
처음 실행할 때 **캘린더**와 **알림** 권한을 허용해야 일정과 9시 알림이 동작합니다.

구글 캘린더 일정이 보이지 않으면 휴대폰 설정 > 계정 > Google에서 캘린더 동기화가 켜져 있는지 확인하세요.

## 빌드
```bash
./gradlew assembleCatholicDebug assembleGeneralDebug
```
`VERSION` 파일의 버전을 올려 main에 푸시하면 GitHub Actions가 두 버전 APK를 빌드해 `v<버전>`(일반용)과 `v<버전>-catholic`(천주교인용) Release로 올립니다.

> 저장소에 포함된 `app/debug.keystore`는 공개 디버그 키입니다. 업데이트 설치가 끊기지 않도록 고정해 둔 것이며, 스토어 배포용이 아닙니다.
